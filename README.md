# erisilebilir-wordpress-tema
bu tema classic widget özelliği kullanılarak inşa edildi. tamamen erişilebilirdir.

## Erişilebilir Tema

Klasik widget tabanlı, Bootstrap 5 hamburger menülü, WCAG uyumlu WordPress teması.

- **Renkler:** Görünüm > Özelleştir > Tema Renkleri; header ve footer rengi açılır kutudan seçilir (kontrastı onaylı renkler).
- **Menüler:** Görünüm > Menüler'de sınırsız menü ve çok seviyeli alt menü oluşturun (sayfa, yazı, kategori, özel bağlantı). "Üst Menü" / "Alt Menü" konumlarına atayın veya Header/Footer widget alanlarına "Gezinti Menüsü" widget'ı ekleyin (sınırsız adet).
- **Erişilebilirlik:** içeriğe geç bağlantısı, odak göstergesi, ARIA etiketli menüler, `aria-expanded` düğmeleri, ekran okuyucu metinleri.

Temayı `wp-content/themes/` altına kopyalayıp etkinleştirin.
